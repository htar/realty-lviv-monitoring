# Команди Telegram-бота

Бот приймає команди лише з чату, ID якого дорівнює `BOT_CHAT_ID`. Зміни застосовуються одразу та зберігаються у SQLite.

## Звичайні команди

| Команда | Призначення | Приклад |
|---|---|---|
| `/start`, `/help` | довідка | `/help` |
| `/status` | статистика обробки | `/status` |
| `/filters` | активні фільтри | `/filters` |
| `/budget` | максимальна ціна, 1 000–1 000 000 грн | `/budget 25000` |
| `/rooms` | кімнатність від 1 до 10 | `/rooms 1,2` |
| `/district` | один або кілька районів | `/district Шевченківський, Франківський` |
| `/strict on` | вимагати явний район | `/strict on` |
| `/strict off` | дозволити оголошення без району | `/strict off` |
| `/rescan` | перевірити історію та повторити пропущені доставки, 1–30 днів | `/rescan 2` |
| `/nobroker on/off` | приховувати оголошення посередників або лише позначати їх | `/nobroker on` |
| `/exclude` | показати, додати (через кому) або очистити (`off`) слова-виключення | `/exclude подобово, хостел` |
| `/saved` | список збережених оголошень | `/saved` |
| `/unsave` | видалити зі збережених за номером зі `/saved` | `/unsave 2` |
| `/why` | найчастіші причини відхилення за N днів (1–90, типово 7) | `/why 7` |

## Кнопки під оголошенням

- **⭐ Зберегти** додає оголошення до `/saved`.
- **🙈 Сховати** видаляє повідомлення з чату.

## Автоматичні дії

- **Дублікати.** Якщо та сама квартира (той самий телефон, кімнати й ціна, або однаковий текст) уже надсилалась протягом 7 днів, повтор з іншого каналу не надсилається.
- **Зміна ціни.** Якщо автор відредагував оголошення і ціна змінилась, приходить повідомлення «💸 Змінилась ціна: 20 000 → 18 000 грн».
- **Валюта.** Ціни в $ і € перераховуються в гривні за курсом НБУ (оновлюється кожні 6 годин). В оголошенні показується і вихідна сума.
- **Щоденний підсумок** о 21:00 за Києвом: скільки переглянуто, збігів, середня ціна та головні причини відхилень.
- **Резервна копія** бази раз на добу в `data/backups/`, зберігаються останні 7.

`/rescan 2` закриває два аварійні сценарії: завантажує повідомлення, які з’явилися під час простою listener-а, і повторно надсилає записи з `matched=1`, для яких `notified_at` залишився порожнім після збою Bot API.

## Приховані адміністративні команди

Вони не показуються у звичайній `/help`, але так само захищені перевіркою `BOT_CHAT_ID`.

| Команда | Призначення | Приклад |
|---|---|---|
| `/channelhelp` | довідка з джерел | `/channelhelp` |
| `/channels` | активні канали | `/channels` |
| `/channeladd` | додати або активувати | `/channeladd @direct_rent` |
| `/channelremove` | вимкнути | `/channelremove @direct_rent` |

Додавати можна username або посилання:

```text
/channeladd @direct_rent
/channeladd https://t.me/direct_rent
```

Username: 5–32 латинські літери, цифри або `_`. Команда не вступає в канал автоматично; listener-акаунт повинен мати до нього доступ.

## Пріоритет налаштувань

- `config/search.json` містить початкові значення. Необовʼязкові поля фільтрів: `excludeKeywords` (масив слів), `hideBrokers` (true/false), `districtAliases` (мікрорайони та вулиці для району, наприклад `{"Шевченківський": ["рясне"]}`; Замарстинів, Голоско, Збоїща, Клепарів і вул. Варшавська вже вбудовані).
- Після зміни командами фільтри й активні канали записуються в таблицю `settings` SQLite.
- Значення SQLite мають пріоритет після наступних запусків.
- `/channelremove` не видаляє історію повідомлень; `/channeladd` знову активує username.

Поточний профіль підтримує тільки оренду квартир у Львові. Канали продажу можуть бути активними джерелами, але оголошення про продаж не проходять орендний фільтр.
